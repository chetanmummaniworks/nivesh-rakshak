# 🎯 Problem Statement

Financial scams are becoming increasingly sophisticated.

A fraudulent message can look like a legitimate investment opportunity, bank communication, loan offer, or government-backed scheme.

Common examples include:

- Guaranteed or unrealistic returns
- Fake investment opportunities
- Urgent payment requests
- Advance or processing fees
- Suspicious loan offers
- Requests for OTPs, PINs, passwords, or card information
- Fake bank or government affiliations
- Suspicious links
- Pressure to act immediately

Many users cannot easily determine whether a financial message is trustworthy before taking action.

This creates a need for a simple system that can help users **pause, understand the warning signs, and verify the claim before acting**.

---

# 💡 Our Solution

NiveshRakshak acts as a digital **investor-safety companion**.

Instead of simply saying:

> "This is a scam."

the system identifies potential warning indicators and explains **why the message deserves caution**.

The platform combines:

- Rule-based financial risk detection
- Machine-learning-based risk classification
- AI-powered investigation
- AI-based image text extraction
- URL analysis
- Conversation analysis
- Voice input
- Verification guidance
- Before-you-pay safety checks
- Guided AI safety assistant

The goal is to help users make **safer and more informed decisions**.

# ✨ Key Features

## 1. 📝 Message Analysis

Users can paste a suspicious financial message and analyze it instantly.

The system looks for indicators such as:

- Guaranteed returns
- Fixed returns
- Unrealistic profits
- Risk-free investment claims
- Urgency
- Payment requests
- Advance fees
- Sensitive information requests
- Suspicious loan terms
- Unverified bank affiliations
- Authority or approval claims
